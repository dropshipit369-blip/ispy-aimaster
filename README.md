# iSpy AI — Resale Intelligence Platform

> Point. Scan. Profit. AI-powered resale intelligence for Australian secondary markets.

## Stack

- **React 19** + TypeScript 6 + Vite 8
- **Tailwind CSS v4** (CSS-first configuration)
- **Supabase** Auth + Database
- **Vercel** Deployment

## Getting Started

```bash
npm install
npm run dev
```

## Features

- Instant AI item identification via camera
- Real-time Australian resale comps (eBay AU, Depop, 1stDibs)
- Net profit margin calculation (after fees & shipping)
- Authenticity verification
- Sell-through velocity analytics
- Dark mode curator scan interface
